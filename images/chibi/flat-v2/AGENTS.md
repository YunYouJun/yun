# 小云动作资产

- 作者通过自然语言让 Codex 调动作；默认修改 `motions/*.json`，保留预览和必要微调入口。
- `yun-flat-v2.svg` 和参考 PNG 是已认可外观。调整动画时保持源文件、哈希、几何、渐变与绘制顺序。
- `rig.json` 用原路径索引控制面部、处理头发遮挡，头发跟随来自位移场。它不是全身骨骼。
- 动作时间单位为秒，关键帧顺序、动作总长、眨眼边界与口型说话段必须通过 Studio 的 `pnpm xiaoyun:motion validate`。
- 新动作可以另存 JSON；预览和导出使用 Studio 的同一编译器。只改动作无需重新生成整张角色图。
- 静音口型不是配音同步；动画预设目前是试验，技术通过不等于作者采用成片。
- 不把实验日志、本机路径、生成工程或视频复制到本目录；许可与原设来源见 README 和 manifest。
